One funny line about crypto trading life, written by a small program to `entry.txt` for make.fun's "Laugh Track: The Crypto Trading Joke Contest" bounty — a single joke about the trader whose strategy is buy high, sell low, and tell the group chat he's accumulating, judged head-to-head against the rest of the field.

## Run it

```sh
node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/entry.txt` when run locally).
